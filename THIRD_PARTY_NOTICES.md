# Third-party source

`AutoScore-master/` contains the AutoScore 1.1.0 runtime source and function documentation from the local research project. Its upstream project is https://github.com/nliulab/AutoScore. Author information, package dependencies, citation, and the declared `GPL (>= 2)` license are retained in `DESCRIPTION` and `inst/CITATION`. The GPL version 2 text is provided as `COPYING` in the publication package.

The publication package omits AutoScore's bundled example datasets, example images, and vignettes. The binary classification experiment does not require them. Its runtime R source is copied without changes. Please preserve the original authorship and license notices when redistributing third-party source.
